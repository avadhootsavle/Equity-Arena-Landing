# Equity Arena — Marketing Landing Page

A high-performance, real-time marketing landing page for **Equity Arena** ("Smart moves start here"). Featuring dynamic market tickers, 3D interactive hero terminals, sector performance breakdowns, and live market data integration.

![Equity Arena Landing](https://raw.githubusercontent.com/avadhootsavle/Equity-Arena-Landing/main/public/preview.png)

## 🚀 Features

- ⚡ **Live Stock Market Ticker**: Real-time simulated price stream for 15 primary arena assets.
- 📊 **3D Interactive Hero Terminal**: Timeframe selector (1M, 15M, 30M, 1H) and custom composite index chart.
- 🎨 **Modern Aesthetics**: Built with Space Grotesk typography, glassmorphism, HSL tailwind gradients, and smooth micro-animations.
- 📱 **Fully Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with reduced-motion support.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/avadhootsavle/Equity-Arena-Landing.git

# Navigate into the project
cd Equity-Arena-Landing

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## ☁️ Deployment on Vercel

This repository is pre-configured for one-click deployment on Vercel:

1. Import repository to Vercel.
2. Framework Preset will auto-detect as **Vite**.
3. Deploy!
